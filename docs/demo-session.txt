colloquy> about
Colloquy is conversation-native. It has no files, pipes or sockets.
 * Transcripts: the one kernel object. Append-only logs of authored turns.
 * Seats: unforgeable rights (listen/speak/invite) to one transcript.
   A program is born holding only its inbox; it reaches nothing else
   until invited. Programs run in ring 3, in their own address spaces.
 * Hash chain: each turn carries SHA-256 of the one before it, so any
   change to history is detectable (try: tamper, then verify).
 * Budgets: CPU is a per-second allowance, not a priority.
 * The kernel is a participant: this shell asks it questions on kernel.desk,
   and it narrates its own decisions in kernel.ledger.
