Type 'help' for commands, 'about' for what makes this OS different.
colloquy> 
colloquy> about
Colloquy is conversation-native. It has no files, pipes or sockets.
 * Transcripts: the one kernel object. Append-only logs of authored turns.
 * Seats: unforgeable rights (listen/speak/invite) to one transcript.
   No global namespace; you can only reach what you were invited to.
 * Hash chain: each turn carries SHA-256 of the one before it, so any
   change to history is detectable (try: tamper, then verify).
 * Budgets: CPU is a per-second allowance, not a priority. A task that
   spends it waits, even on an idle machine (see the hog in ps).
 * kernel.ledger: the kernel narrates its own decisions as turns.
